# Contributing

Focused fixes and improvements are welcome.

1. Open an issue describing the behavior and expected inventory invariant.
2. Create a short branch from `main`.
3. Add or update tests for every business-rule change.
4. Run the backend, frontend, and container checks documented in the README.
5. Submit a pull request explaining the operational impact and rollback path.

Do not include production inventory, credentials, or personal information in fixtures or bug reports.
